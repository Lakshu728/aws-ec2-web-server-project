# AWS EC2 Web Server Project

## Project Description
Deployed a static website on AWS EC2 using Apache Web Server.

## Steps Performed
1. Launched EC2 instance (Amazon Linux 2)
2. Configured Security Group (SSH, HTTP)
3. Installed Apache
4. Deployed website
5. Verified public access

## Commands Used
sudo yum install httpd -y
sudo systemctl start httpd
sudo systemctl enable httpd

## Outcome
Successfully hosted live website on AWS EC2.
